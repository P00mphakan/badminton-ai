สถาปัตยกรรมครบจบ: Deploy + Database + AI Engine + ประหยัดเน็ต

พร้อมใช้งานจริงบนมือถือทันทีโดยไม่ต้องส่งสตรีมวิดีโอขึ้นเซิร์ฟเวอร์

1. Deploy ที่ไหนดี? (ฟรี + HTTPS สำหรับกล้อง)

แนะนำ Cloudflare Pages หรือ Vercel หรือ Firebase Hosting เพราะให้ HTTPS อัตโนมัติ (iOS บังคับใช้ HTTPS ถึงจะยอมให้เปิดกล้องได้) และมี CDN ทั่วโลก โหลดไวมาก

2. ใช้ Database อะไรดี?

• ในเครื่อง (Offline): ใช้ IndexedDB เก็บพิกัดการวิ่งระหว่างตีแบด (ไม่เสียเน็ตเลย)
• บน Cloud: ใช้ Supabase (PostgreSQL) หรือ Firebase Firestore ซิงค์เฉพาะไฟล์ JSON สรุปหลังจบเกม (ใช้เน็ตแค่ ~15 KB ต่อแมตช์)

3. ต้องใช้ AI Engine อะไรเพิ่มไหม?

• ตรวจจับผู้เล่น 4 คน: ใช้ MediaPipe Pose / YOLOv8n (WebGPU / TensorFlow.js) รันบนชิป iPhone โดยตรง
• จับความเร็วลูกแบด: ใช้ TrackNetV3 (ONNX Runtime Web) รันบนเบราว์เซอร์
• โค้ชวิเคราะห์: ใช้ Gemini Flash API ส่งเฉพาะตัวเลขสถิติไปถาม

4. ลดการใช้ Mobile Data ได้อย่างไร?

ห้ามอัปโหลดคลิปวิดีโอขึ้น Cloud! ให้ประมวลผลภาพกล้องและคลิปวิดีโอด้วยชิปในมือถือ (Edge AI 100%) แล้วส่งเฉพาะข้อความสรุปสถิติเมื่อกดปุ่มถามโค้ช AI เท่านั้น ประหยัดเน็ตได้ถึง 99.9%
